# @deepseek-ai/dsh-client-ui-settings-bots

[English](README.md) | 中文

## 概述

`dsh-client-ui-settings-bots` 添加一个 Settings 区块：这个组织运行着哪些 bot、每一个是干什么的、以及它运行所用的是什么。管理员给一个 bot 起名、写下它的性格和职责，再从部署提供的那些 agent preset 里挑一个；被安装自己的文件写下的 bot 只展示、不提供编辑，因为下一次启动会把那个文件再读一遍。一个 preset 已不再被部署提供的 bot 会被展示并标出来，而不是藏起来，因为有人写下的那段性格比运行它的那一行活得更久。

<a id="use-this-package"></a>
## 使用本包

Web bundle 把它挂在其他 Settings 区块旁边：

```yaml
- id: ui-settings-bots
  name: '@deepseek-ai/dsh-client-ui-settings-bots'
```

没有别的要配置的。这个区块在打开时读 `remote.bots`，并渲染四样东西之一：那些 bot 和那些团队连同它们的表单、一条「这个部署不维护自己的机器人」的提示、一条「调用方不能更改它们」的提示，或者一次带重试的失败。每一个 bot 行还能和那个 bot 开一场对话——走工作区导航，而不是在这里创建会话，于是它落在读者所在的那个工作区，并像其他每一个新会话那样被打开。

<a id="understand-the-implementation"></a>
## 理解实现

**三种回答，其中只有一种值得重试。**一个不维护机器人的部署，不会在读者等待时长出一个来；一个没有那个身份的调用方，再问一遍也不会获得它。只有读取失败才配一个按钮。

**能力是挑出来的，不是敲进去的。**preset 控件提供的正好是 `remote.bots.presets` 答出来的那些，而那也正是部署用来校验一次保存的同一份列表。这里放一个自由文本字段，会让管理员指名一套没人审过的组合，也会拒绝掉表单刚刚自己给出的选项。

**被写下的 bot 只展示、不提供编辑。**那一行会说明安装的配置拥有它，并且不带编辑和移除：在这里被接受的修改会在下一次启动时被撤销，而界面就等于报告了一件不真实的事。

**一个跑不起来的 bot 会被标出来，而不是藏起来。**它的 preset 离开了 profile，所以它开不了对话；删掉那一行会丢掉管理员写下的性格，而藏起来会让他去找一个其实还在的 bot。

**对被写下的 bot 也提供交谈。**运维方自己的那些 bot 正是最值得交谈的；只有修改它们才会被拒绝。唯一开不了对话的那一行，是 preset 已不再被部署提供的那个，而它会说明这一点。

**团队的成员是挑出来的，不是敲进去的。**一个团队只能装它自己组织的 bot，所以成员列表就是这个读者已经在维护的那些 bot。一个还没有任何 bot 的部署会直接说明情况，而不是摆出一个空表单：那时团队没有任何可装的东西。

**移除要先问一遍。**这个 bot 会停止运行并离开名册，而它拥有的那些对话仍归属于它、却再没有人会在里面作答，所以它走共享的风险确认，而不是一次点击。

<a id="model-experience"></a>
## 模型体验

无，因为本包不注册任何工具或提示词：它渲染一个配置界面，它展示的东西都不会进入模型请求。

#### KV Cache 影响

请求前缀不变，因为这里没有任何东西参与请求装配。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **这是唯一的入口** — 和 bot 的对话只能从这一页开始；新建会话的界面、侧边栏和输入框里都没有 bot。
- **每个表单一个组织** — 两个表单都把组织当文本收，所以同时管理两个组织的读者要重复输入；两个都不把他管得着的那些组织做成可选项。
- **团队的成员只能是本页的 bot** — 选择器列的是这一页上的 bot，所以一个平台管理员在编辑另一个组织的团队时，只有在读取答出那个组织的 bot 之后才看得到它们。
- **这个区块对每个读者都显示** — 一个成员打开 Settings 会看到它，并读到「你不能更改这个组织的机器人」的提示，而不是根本看不到这个区块。要把它藏起来，导航得在区块自己的读取答出来之前就知道调用方的身份。
- **组织是敲进去的，不是挑出来的** — 表单把组织 id 当文本收，因为客户端这边还读不到任何组织目录。
- **性格只是一个纯文本框** — 没有办法预览一个 bot 会以什么样的系统提示词运行，也没有办法在保存前试一试。
- **没有分页也没有搜索** — 调用方管得着的每一个 bot 都一次性列出来。

**Runtime invariant:** 不发布伴生检查。这个区块从一次读取和它自己那些调用的结果来渲染；没有第二份副本可以和部署的说法不一致。
