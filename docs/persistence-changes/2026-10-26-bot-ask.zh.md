<a id="compatibility"></a>
## 兼容性

已有记录仍然有效：两个事件都是新的，没有 bot 问过任何东西的会话都不带它们。不认识这两个类型中任一个的构建会拒绝该日志，而不是在缺少模型据以行动的那个答复的情况下读这场对话——这正是预期的读法：答复会进入模型，默默丢掉它的读者会把这个 agent 被告知了什么报错。两个事件故意分成两个根：一个记录这场会话学到了什么、从谁那里学到，另一个记录谁问了这场会话的 bot 什么，而任一侧的读者只看到自己那一侧。
