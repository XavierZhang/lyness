## Compatibility

Existing records remain valid: both events are new, and a session where no bot asked anything carries neither. A build that does not know either type refuses the log rather than reading the conversation without the answer the model acted on, which is the intended reading — the answer reaches the model, and a reader that silently dropped it would misreport what the agent was told. The two events are deliberately separate roots: one records what a session learned and from whom, the other records who asked this session's bot what, and a reader of either side sees only its own.
